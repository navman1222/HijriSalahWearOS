# Hijri Salah Wear OS — v1.0.0

A simple Wear OS application for keeping track of the five daily prayers directly from your watch.

## Features

* **Five daily Salah times** — enter and view the times for Fajr, Dhuhr, Asr, Maghrib, and Isha.
* **Next Salah** — shows the upcoming prayer and how long remains until it begins.
* **Countdown display** — when the next Salah is less than one hour away, the display can show the remaining minutes.
* **Salah time display** — outside the countdown period, the watch displays the scheduled time of the next Salah.
* **Watch-side operation** — the Salah times can be entered and managed directly from the watch without requiring a companion phone application.
* **Maghrib handling** — Maghrib is treated separately so that the prayer cycle can correctly move from Maghrib towards Isha and then back to Fajr.
* **Pujie Watch Face compatibility** — designed with use alongside Wear OS watch faces and complications in mind.
* **Hijri date** — includes a Hijri date complication for displaying the Islamic date on compatible watch faces.

## Why I Made It

I wanted a small, straightforward Wear OS application that would let me keep my Salah times on my watch without relying on my phone for the basic functionality.

The project is deliberately simple and is intended to be useful alongside a watch face rather than trying to become a large, all-in-one prayer application.

* Designing parts of the application structure
* Debugging errors
* Explaining Android and Wear OS development concepts

The final application was assembled, tested, and released by me. In other words, this is an **AI-assisted project**, rather than code that I have written entirely by hand.

I am making this clear because I think it is useful for users and other developers to know how the project was produced.

## Installation

Download:

**`HijriSalahWearOS`**

and install it on a compatible Wear OS device using ADB or another suitable APK installation method.

> **Important:** This application is currently provided as an APK rather than through Google Play. Installation therefore requires sideloading.

## Device

Developed and tested for **Wear OS**, including the TicWatch E3.

Other Wear OS watches may work, but compatibility has not necessarily been tested on every device.
